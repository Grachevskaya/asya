**Asya** 是 Ferry/nopanamaman 的视觉小说《Z.A.T.O // I Love the World and Everything In It》的主角。

## 外貌

Asya 留着凌乱的深棕色短发，刘海刚好到耳下。她的眼睛是深金色，瞳孔为黄色。

她的所有立绘都穿着女生校服：一条深棕色长袖连衣裙，配白色蕾丝衣领、滚边与袖口。裙外套着一条带大口袋
的黑色围裙，右侧别着一枚小徽章，一般认为那是共青团的徽章。

## 背景

Asya 在沃尔库塔-5 长大。那是一座被称为 Z.A.T.O. 的封闭城市，她在这里生活并上学。

## 性格

Asya 是个安静的女孩，在班上被视为异类。故事开始时，她说话总是说到一半就没了声，或者结巴；Vadim
取笑她时如此，她第一次与 Marina 和 Ira 说话时也是如此。随着剧情推进，她和 Marina 交谈渐渐自如，
最后也能与 Vadim 交谈。

她对人生有一套复杂的看法。她深怀自卑，觉得自己不配被爱，却又无私而善良，坚称自己热爱这个宇宙：
"宇宙对我这种不知感恩的小鬼太好了。" 作为一种承受机制，她习惯把痛苦转成享受，常常觉得事情本可以更
糟。

她有时会失控：一旦感到被抛弃的迹象，就会害怕甚至悲伤。矛盾的是，在任何非社交的场合她都非常坚定——
即使面对虚无主义这样的概念，她也看不出有什么可动摇的。她对哲学理解得极好，同时又深陷于自己古怪的
幻想，甚至能说服自己读一本童话书是"非凡的启示"。

## 关系

### Ira Grachevskaya

Ira 多次把 Asya 从欺凌与纠缠中救出来，最出名的一次是她朝 Vadim 扔了把椅子。Asya 对 Ira 抱有一种复杂
的感激：她愿意把这段关系看作友情，却也明白这份"友情"多半是单向的。从剧情开始到接近尾声，Ira 一直
在 Asya 的生活中处于中心位置。

### Vadim Garin

Vadim 是 Asya 痛苦的主要来源，实际上带着同学对她做各种残忍的"恶作剧"，而 Asya 只能忍受。他经常抄
Asya 的作业。两人曾与 Marina 一起出去玩过一次，但这对他在之后的剧情里如何对待她毫无影响。

### Marina Kaplan

Marina 是 Asya 的朋友。两人起初是为了讨论 Ira 的失踪而见面，逐渐建立起友谊。正是 Marina 让 Asya 知道
了自己一直把生病的 Ira 藏在家里。

### Tosya

Tosya 究竟是疾病的产物、Asya 意志力的化身，还是一个真实的人，并不清楚。她是 Asya 的密友，直到剧情
开始前不久从 Asya 的生活中消失，后来才重新出现。

### Lev Kaplan

Lev 是 Marina 的哥哥，也是她的照料者。他向 Asya 揭示了这种疾病的本质，并为她做了一次评估测试。能够
压制病情的药也是他给的；Asya 拒绝服用，却想把它送给自己的父母。

## 琐事

* Ferry 在游戏内画廊的速写本部分画过 Asya 的性别转换版本，以及其他主要角色。
* Asya 虽然年纪不小了，却喜欢读童书。
* 从她的所在地与制服上的徽章来看，Asya 属于共青团，即苏联共产党的青年组织。
* 游戏结尾暗示，沃尔库塔-5 周边探测到的信号来自她：她用俄文摩尔斯电码写下的"我爱你"在城市周边地区
  可以被接收到。
* 她喜欢喝一种叫 Duchess 的饮料。

**asya** 是一个包名过滤器。

## 关于该模块

虽然“检测安装的应用”是不正确的做法，但是并不是所有的与 root 相关联的插件类应用都提供了随机包名支持。这就意味着检测到安装了此类应用（如 Fake Location 、存储空间隔离）与检测到了 root 本身区别不大。（会使用检测手段的 app 可不会认为你是在“我就蹭蹭不进去”）

与此同时，部分“不安分”的应用会使用各种漏洞绕过系统权限来获取你的应用列表，从而对你建立用户画像。（如陈叔叔将安装了 V2Ray 的用户分为一类），或是类似于某某校园某某乐跑的软件会要求你卸载作弊软件。

一些应用采用 syscall 来检测 uid 运行却无法查询，从而判断出未知应用遭到了隐藏；对此我们用
[tosya](https://github.com/Grachevskaya/tosya) 来做伪装。
